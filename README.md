FastAPI Machine Learning Service
📌 Описание проекта
Проект посвящен созданию веб-приложения и REST API с использованием фреймворка FastAPI для развертывания и интерактивного тестирования модели машинного обучения.
🛠 Выполненные задачи
Создание API: разработка эндпоинтов для приема клиентских запросов и передачи данных в модель.
Интеграция с ML: подключение обученной модели для выполнения предсказаний «на лету».
Тестирование сервиса: проверка работоспособности через встроенную документацию FastAPI (Swagger UI).
🧰 Технологический стек
Python (FastAPI, Uvicorn, Pydantic)
